🔍 What is Geo Interface Pro?

Geo Interface Pro is a lightweight, browser-based mapping utility for entering latitude/longitude, adding and managing markers, and zooming or fitting views dynamically. Built using **Flask** and **Leaflet.js**, it’s designed for clarity, speed, and reliability. It helps you work with geographic data effortlessly.

Quick Start Guide

Add Location

Add a marker by entering latitude and longitude. The tool automatically geocodes names.

Manage Markers

Manage and clear markers easily from the sidebar using 'Clear All' or 'Fit to markers'.

Explore the Map

Switch map layers (OSM/Satellite) or zoom to your default position instantly using controls.
