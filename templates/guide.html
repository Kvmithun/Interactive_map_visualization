Project Overview & Tech Stack

🎯 Application Goal

Geo Interface Pro is a modern, browser-based utility designed for efficient geospatial data visualization. Its primary function is to provide a fast, reliable interface for users to convert and plot coordinate data (Latitude/Longitude) onto an interactive map, manage markers dynamically, and perform automated Reverse Geocoding.

🧱 Technology Stack

Component Technology Role
Backend Flask (Python) Lightweight web server, handles routing and serves assets/templates.
Frontend Map Leaflet.js Core JS library for rendering the interactive map, markers, and base layers.
Geocoding Nominatim API (OSM) External service for Reverse Geocoding (coordinates to address).
Client Logic Vanilla JavaScript (ES6+) Manages all front-end interactivity, AJAX calls, and custom UI elements.

⚙️ Workflow: Request to Render

The application follows a standard Client-Server architecture. The primary challenge is managing asynchronous network calls for geocoding without locking the user interface.

Step Component Action & Data Flow
1. Startup Browser ➡️ Flask Flask serves map.html and all static assets (CSS, JS).
2. Map Init Leaflet.js Map canvas initializes; controls (Zoom, Layers) and base layers are added.
3. User Interaction Browser ➡️ map.js User clicks map or clicks "Add Marker."
4. Geocoding (Async) map.js ➡️ Nominatim API JavaScript executes an async fetch() to convert coordinates to a place name.
5. Marker Creation map.js ➡️ Leaflet Once the name is received, the marker is rendered, and its data is saved to localStorage.
6. UI Feedback map.js A Toast Notification appears to confirm the action, replacing disruptive native alerts.

🚀 Local Development Setup

The application can be run locally using a standard Python environment with the Flask framework installed.

📦 Installation Steps

  1. Install Python dependencies: pip install -r requirements.txt
  2. Run the Flask server: python app.py
  3. Access the application at: http://127.0.0.1:5000/

💾 Data Persistence

Marker data is stored entirely on the user's browser via localStorage. Note that data is explicitly cleared every time the map page loads to ensure a fresh experience (controlled by localStorage.removeItem(STORAGE_KEY) in map.js).

📐 Template Routing

The Flask application uses the following routing configuration:

@app.route('/')
def index(): return render_template('index.html')
@app.route('/map')
def map_page(): return render_template('map.html')
@app.route('/guide')
def project_guide(): return render_template('guide.html')

✨ Custom UI & Marker Management

Custom UI Elements

Toast Notification Small, non-blocking pop-up at the bottom center. Replaces alert() for smooth feedback.
Custom Modal Used for the irreversible Clear All Markers confirmation, replacing native confirm().
Address Autofill Input field is instantly updated after map click using reverse geocoding.

📋 Marker List Details

The sidebar's "Markers List" panel provides comprehensive controls for each location:

Detail Controls
Location Name Displayed prominently, styled with the marker's custom color.
Coordinates Displayed below the name, showing Lat/Lng up to 4 decimal places.
Zoom Button Centers the map and zooms in to the specific marker's location.
Edit/Color/Remove Clicking "Edit" opens the marker's popup, allowing the user to update the label, change the color, or delete the single marker.

💡 Future Scope & Enhancements

While fully functional, Geo Interface Pro can be expanded with the following enhancements:

  • Forward Geocoding: Implement a search bar that converts a typed address into coordinates, centering the map automatically.
  • Persistent Storage: Integrate a lightweight database (e.g., SQLite) to save marker data across server sessions, moving beyond browser-only localStorage.
  • Map Icon Customization: Allow users to select different SVG icon or colors for their markers.
  • Routing Integration: Add the ability to select two markers and display a travel route between them using an engine like OSRM.
